Featured Capstone Artifact

The primary artifact featured within this portfolio is the Travlr Getaways Full-Stack Web Application, originally developed during the Software Development program coursework and enhanced during the Computer Science Capstone experience.

The application was enhanced in three major categories that demonstrate my growth as a software developer and computer science professional:

  • Software Design and Engineering – Improved software architecture, application organization, maintainability, and code quality.
  • Algorithms and Data Structures – Implemented pagination, search functionality, sorting algorithms, and performance improvements to increase application scalability.
  • Databases – Enhanced MongoDB schema validation, indexing strategies, data integrity controls, and database error handling.

Together, these enhancements demonstrate my ability to evaluate an existing software system, identify opportunities for improvement, and implement solutions that improve functionality, performance, security, and maintainability.
